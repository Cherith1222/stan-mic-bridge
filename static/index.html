將 Mac 麥克風傳到 Windows

透過加密連線，讓 Windows 上的 Typeless 使用這台 Mac 的麥克風。

開始後會自動嘗試恢復短暫中斷。按「停止」或關閉分頁，才會結束這次收音；若瀏覽器撤銷麥克風權限，需手動重新開始。

尚未開始

連結未自動帶入時，請貼上連線碼。只保留在此頁面，重新整理後需再次貼上。

0

音訊僅在按下開始並允許麥克風後傳送。

  1. 按「開始傳送麥克風」，允許瀏覽器使用麥克風。
  2. 確認顯示「正在傳送」後，切回 RustDesk 的 Windows 遠端畫面。
  3. 點選要輸入文字的 Windows 應用程式，再按 Typeless 快捷鍵說話。
  4. 使用期間保持這個 Mac 瀏覽器分頁開啟；完成後按「停止」，Windows 會切回原本的實體麥克風。

開始傳送會將 Windows 預設麥克風切到 Mac 音訊；停止或斷線後還原。Windows 上其他使用預設麥克風的程式也可能跟著切換。音量表只表示本機收到聲音；請在 Windows 確認 Typeless 實際辨識結果。請勿分享連線碼。
